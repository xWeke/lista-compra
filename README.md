# Lista de la compra

Lista de la compra compartida en tiempo real (React + Vite + Supabase), instalable en el iPhone como PWA y publicada en GitHub Pages.

```bash
npm install
cp .env.example .env   # rellenar URL y anon key de Supabase
npm run dev            # http://localhost:5173/lista-compra/
```

Documentación del proyecto, convenciones y fases: [CLAUDE.md](CLAUDE.md).
